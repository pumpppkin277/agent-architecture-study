# Agent Systems 学习路线

12 周、84 天的计算机基础与 Agent 架构学习路线。首页包含每日主题、实践任务、每周验收和学习资源，学习进度保存在当前浏览器中。

## 本地运行

直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
